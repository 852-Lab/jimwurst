# Basic Settings

The **Basic Settings** page handles individual user configuration and profile details.

---

## User Profile Configuration

- **Work Email**: Primary corporate email used for identification, communications, and attribution.
- **Personal Prompts (Upcoming)**: A planned feature allowing users to define custom persona rules or system prompts. This lets individual analysts customize how Kowalski responds to them (e.g., requesting concise bullet points, specific SQL syntax styles, or verbose statistical explanations).
