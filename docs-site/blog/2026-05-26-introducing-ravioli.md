We are thrilled to officially introduce **Ravioli**, a lightweight, high-performance local data warehouse tool designed for modern data engineering workflows. Powered by **DuckDB**, Ravioli makes running transformations, defining relational SQL models, and executing tests on your local machine incredibly simple and fast.

<!-- truncate -->

## Why Ravioli?

For years, setting up a data warehouse meant spinning up heavy, expensive cloud instances or dealing with complex local databases. Data engineers had to compromise between local speed and production-like transformation layers.

Ravioli solves this by combining:
1. **The speed of DuckDB**: In-memory vectorized query execution.
2. **The structure of modern analytics engineering**: Modular SQL models, schemas, and assertions.
3. **Developer-friendly workflow**: No configurations or cloud credits needed to start building.
